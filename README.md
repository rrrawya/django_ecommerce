Full Stack E-commerce Web Application (Django)

📌 Overview

Developed a dynamic e-commerce web application using Django, enabling users to browse products, view detailed information, and manage a shopping cart through a clean and user-friendly interface.

🚀 Key Features
	•	Dynamic product listing from database using Django ORM
	•	Product detail pages
	•	Shopping cart functionality (add items)
	•	Search functionality
	•	Responsive UI using Bootstrap
	•	Admin panel for managing products

🛠️ Technologies Used
	•	Python (Django Framework)
	•	HTML, CSS, Bootstrap
	•	MariaDB (Database)

💡 Highlights
	•	Implemented dynamic data rendering using Django templates
	•	Used Django ORM for efficient database operations
	•	Applied MVC (MVT) architecture to structure the application
	•	Built a scalable and maintainable project structure
